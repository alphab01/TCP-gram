## Мессенлжер на TCP

использование:

запускаем main.go и после консольную утилиту

```
nc localhost 8080
```
(если хотим запустить в другом месте, просто меняем в main.go 120-ую строчку)

теперь вы подключены как клиент, можно писать сообщения и другие участники чата будут их видеть

команды:

/nick, /nickname - меняет ник вашего клиента для всех участников чата

/quit - выход из чата, при выходе участники чата получат уведомление что вы вышли
